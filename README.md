# 图书管理系统

这是一个基于Vue.js前端和Flask后端的图书管理系统，提供完整的图书管理功能，包括图书的增删改查、借阅管理、用户管理等。

## 功能特点

- 📚 图书管理：添加、编辑、删除、搜索图书
- 👥 用户管理：管理员和普通用户角色
- 📖 借阅管理：借书、还书、续借功能
- 📊 统计分析：借阅统计、热门图书等
- 🌐 响应式设计：适配不同设备屏幕

## 技术栈

### 前端
- Vue.js 3
- Element Plus UI组件库
- Axios HTTP客户端
- Vue Router 路由管理
- Pinia 状态管理

### 后端
- Flask Web框架
- SQLAlchemy ORM
- MySQL数据库
- JWT认证
- Flask-CORS跨域支持
